# --- LLM 호출 전체 (AI-07 하네스/AI-09·14 RAG 생성/AI-12 세션 리포트/고관절 과신전

# 모든 LLM 호출은 boto3 bedrock-runtime 클라이언트의 Converse API(converse())를 직접
# 쓴다 — 벤더 전용 SDK(Anthropic SDK 등)를 쓰면 그 벤더 모델만 호출할 수 있는데, Converse

# 도구 사용(toolConfig)을 지원하는 통합 인터페이스라, 모델을 바꿀 때 코드가 아니라
# 환경변수(각 모듈의 BEDROCK_MODEL_ID 계열 환경변수)만 바꾸면 된다.

# harness.py/rag/generation.py/session/report.py가 공유, HYPEREXTENSION_BEDROCK_MODEL_ID
# — hyperextension_llm_check.py), 그리고 AWS 자격증명(boto3 기본 체인 — 환경변수/
# 프로파일/IAM 롤 중 하나)이 필요하다 — 없으면 모듈별 규칙기반 폴백으로 동작한다(각
# 모듈의 _get_client() 참고).
#
# (2026-08-28 추가) 같은 boto3를 app/pose/dtw_template_store.py도 재사용한다 — DTW
# 템플릿 묶음을 S3에서 받아올 때 쓰는 별도 기능(DTW_TEMPLATES_S3_* 환경변수)으로, 위
# Bedrock 용도와는 다른 AWS 리소스(S3 버킷)를 가리킨다. 이쪽도 환경변수가 없으면 조용히
